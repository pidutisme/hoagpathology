HOAG PATHOLOGY V24 — INVENTORY STOCK VALUATION PATCH

Baseline: V23
Scope: Inventory calculation and inventory transaction persistence only.

Changes:
1. New Stock In and Stock Out movements store unitPrice at the time the transaction is recorded.
2. The API inventory movement schema accepts optional unitPrice for backward compatibility with existing records.
3. Non-admin users cannot alter a previously recorded movement's unitPrice.
4. Monthly Stock In / Stock Out values use each transaction's recorded unitPrice.
5. Monthly movement is recalculated from the transaction ledger instead of trusting stale monthlySnapshots.
6. Last Month Balance is rebuilt from opening stock plus all earlier movements, valued using each movement's recorded unitPrice (legacy records without unitPrice fall back to the saved monthly price for that month).
7. Add/edit/delete refreshes affected month snapshots. Month grouping uses Malaysia/browser-local transaction month parsing to avoid UTC month-boundary errors.
8. Cache query changed from visitor-v18 to visitor-v19.
9. Root app.js and assets/js/app.js are kept identical.

Deployment:
- Deploy the complete extracted folder to Vercel/GitHub.
- No Supabase SQL migration is required.
- After deployment, hard refresh the browser (Ctrl+Shift+R).
- Existing historical transactions without unitPrice use the saved monthlyPrices value as a compatibility fallback. Newly recorded movements will retain their own unitPrice.

Validation:
- npm run build passed (65 files; JavaScript syntax, JSON configuration, filesystem layout, HTML assets).
- npm test: 19 tests passed; 3 test files could not run because the extracted workspace has no installed zod dependency. No test failure was reported for the inventory patch itself.
